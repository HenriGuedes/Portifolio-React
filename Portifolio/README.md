# 💼 Portfólio Pessoal - Henrique Guedes

Este projeto é um **portfólio pessoal** desenvolvido com **React.js**, com o objetivo de apresentar meus projetos, informações profissionais e formas de contato.  
A aplicação conta com uma interface moderna, responsiva e organizada, permitindo que visitantes conheçam melhor meu trabalho e entrem em contato facilmente.

## 🔗 Acesse o Projeto

O site está hospedado na **Vercel**:  
👉 [https://seu-portfolio.vercel.app](https://seu-portfolio.vercel.app)

## 🛠️ Tecnologias Utilizadas

- **React.js**: Framework principal da aplicação.
- **React Router DOM**: Gerenciamento de rotas entre páginas.
- **Tailwind CSS**: Estilização rápida e responsiva.
- **React Icons**: Ícones de mídias sociais e botões.

## 📋 Funcionalidades

- **🏠 Página Inicial (Home)**: Apresentação pessoal com uma breve biografia e botões para acessar redes sociais.
- **📁 Página de Projetos**: Lista de projetos com barra de busca dinâmica e opção de visualizar detalhes individuais.
- **🔍 Busca em Tempo Real**: Filtra os projetos conforme o usuário digita.
- **📄 Página de Detalhes**: Mostra informações completas de um projeto selecionado.
- **📬 Página de Contato**: Formulário funcional que exibe os dados preenchidos em um `alert`, além de opções de contato direto via e-mail ou telefone.
- **📎 Rodapé com Ícones**: Links diretos para **GitHub** e **LinkedIn**.
